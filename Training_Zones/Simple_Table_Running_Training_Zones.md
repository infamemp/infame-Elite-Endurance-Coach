# Running Training Zones Reference Database

This file contains standardized intensity training zones for running across major coaching and scientific methodologies (Daniels, Palladino, Friel, Koop, Olbrich).

## Methodology: Daniels Running Zones
* **Sport:** Running
* **Primary Metrics:** Lactate Threshold (LT) Pace, Lactate Threshold Heart Rate (LTHR)
* **Intensity Anchors:** % LT Pace, % LTHR

| Zone Code | Zone Name | % LT Pace (Est) | % LTHR (Est) | RPE (1-10) |
| :--- | :--- | :--- | :--- | :--- |
| E | Easy | 75–85% | 72–88% | 1–3 |
| M | Marathon | 85–95% | 89–99% | 3–4 |
| T | Threshold | 100% | 100% | 4–5 |
| I | Interval | 105–115% | > 100% | 6–8 |
| R | Repetition | 115–125% | N/A | 9–10 |
